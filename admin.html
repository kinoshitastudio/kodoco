Firebase 未設定状態:
現在 app.html の FIREBASE_CONFIG.apiKey が未設定のため、口コミは各ユーザーの localStorage 内に閉じて保存されています。
他人の投稿は見えないため、モデレーションは不要です。
💡 Firebase 有効化後にできるようになること:
  • 全ユーザーの投稿を一覧で確認
  • 不適切な投稿を Firestore から削除
  • 通報メールに記載された投稿ID (cloudId) で特定可能
具体的な手順と Firestore security rules の雛形は admin-guide.html を参照。
