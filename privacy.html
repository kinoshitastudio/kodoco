プライバシーポリシー

KODOCO は、利用者のプライバシー、特にお子さんに関する情報を最大限尊重します。

最終更新: 2026年5月3日 · 運営: kinoshita studio

01取得する情報

本サービスでは、以下の情報を取得することがあります。

  • アカウント情報: メールアドレス、表示名（handle）、アバター画像
  • お子さんの情報: 年齢グループ・人数のみ（個人を特定する情報は取得しません）
  • 投稿コンテンツ: 口コミ本文、評価、写真、申請されたスポット情報
  • 利用情報: お気に入り、解禁キャラクター、achievements、設定
  • 技術情報: IP アドレス、ブラウザ種別、アクセス時刻（サーバーログ）
お子さんの「氏名・写真・通学先・住所」など、個人を特定できる情報は取得しません。年齢グループ（0〜10歳の区分）のみを使用します。

02利用目的

  1. 本サービスの提供・運営・改善
  2. お子さんの年齢や好みに合わせたスポットの提案
  3. 口コミ・スポット情報の表示
  4. 不正利用の防止、規約違反への対応
  5. お問い合わせへの対応

03第三者提供

本サービスは、以下の場合を除き、利用者の個人情報を第三者に提供しません。

  • 利用者本人の同意がある場合
  • 法令に基づく場合（警察・裁判所等からの正当な要請）
  • 人の生命・身体・財産の保護のために必要があり、本人の同意を得ることが困難な場合

04利用する外部サービス

本サービスは以下の外部サービスを利用しています。各サービスのプライバシーポリシーも併せてご確認ください。

  • Supabase（米国）: アカウント認証、データ保存（東京リージョン）
  • GitHub Pages: 静的ホスティング
  • OpenWeather / Open-Meteo: 天気情報の取得
  • Wikipedia / 各施設公式サイト: スポット画像の参照（直リンク表示、当方サーバーには保存しません）

05Cookie / localStorage

本サービスはブラウザの localStorage を使用して、お気に入り・設定・onboarding 状態などをローカルに保存します。アカウントログイン時は、これらが Supabase 上にも同期されます。

localStorage はブラウザ設定からいつでも削除できます。

06データの削除

アカウントを削除すると、Supabase 上の以下のデータが削除されます。

  • プロフィール情報
  • お気に入り・解禁状態・achievements
  • 投稿した口コミ（公開済みのものは匿名化される場合があります）
  • 申請したスポット情報（承認済みのものは公開を継続する場合があります）

削除依頼は本サービス内の設定画面、または下記お問い合わせ先より承ります。

07セキュリティ

本サービスは、取得した情報の漏洩・滅失・毀損を防止するため、必要かつ適切なセキュリティ対策を講じます。ただし、インターネット通信の性質上、絶対的な安全性は保証できません。

08未成年の利用

本サービスは、保護者が利用することを想定しています。未成年者がご自身でアカウント登録される場合は、保護者の同意のもとでご利用ください。

09プライバシーポリシーの変更

本ポリシーは、必要に応じて変更されることがあります。重要な変更がある場合は、本サービス上で通知します。
