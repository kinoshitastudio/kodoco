利用規約

KODOCO（以下「本サービス」）をご利用いただきありがとうございます。

最終更新: 2026年5月3日 · 運営: kinoshita studio

第1条適用

本規約は、本サービスの提供および利用に関するすべての関係に適用されます。本サービスを利用された時点で、本規約に同意したものとみなします。

第2条サービスの内容

本サービスは、滋賀県およびその周辺における子連れ向けおでかけスポットの情報提供、ならびに利用者間の口コミ・写真等の投稿を可能にする Web アプリケーションです。

本サービスは現在 プロトタイプ段階 で運用されており、完全無料で提供されています。仕様や機能は予告なく変更されることがあります。

第3条アカウント登録

  1. 本サービスの一部機能（口コミ投稿・お気に入り同期・スポット申請等）の利用にはアカウント登録が必要です。
  2. 登録時に正確な情報を提供してください。虚偽の登録が判明した場合、利用を停止することがあります。
  3. パスワードの管理責任は利用者本人にあります。

第4条ユーザー投稿（口コミ・スポット申請・写真）

  1. 利用者は、本サービス上に口コミ・写真・スポット情報等のコンテンツ（以下「ユーザー投稿」）を投稿できます。
  2. ユーザー投稿の内容について、利用者は自ら責任を負うものとします。
  3. 本サービスは、ユーザー投稿を表示・編集・削除する権利を有します（モデレーションのため）。
  4. 本サービスは、ユーザー投稿を本サービスの運営・改善・宣伝のために利用できるものとします（無償・非独占）。

第5条禁止事項

本サービスの利用にあたり、以下の行為を禁止します。

  • 法令または公序良俗に違反する行為
  • 他の利用者・第三者を誹謗中傷、差別、ハラスメント、または不快にさせる行為
  • 子どもの安全・プライバシーを侵害する内容の投稿
  • 虚偽のスポット情報を投稿する行為
  • 他人の著作物・写真を無断で投稿する行為
  • 営業目的のスパム投稿、過度な宣伝行為
  • 本サービスの運営を妨げる行為（過剰なリクエスト、スクレイピング等）

違反が確認された場合、投稿の削除・アカウントの停止・利用禁止等の措置を行うことがあります。

第6条スポット情報の正確性

本サービスに掲載されているスポット情報（営業時間・料金・住所・施設の有無等）は、執筆時点の情報に基づきます。実際の利用前には、必ず各施設の公式サイトまたは電話で最新情報をご確認ください。

掲載情報の不正確性により利用者または第三者に生じた損害について、本サービスは責任を負いません。

第7条知的財産権

  2. 外部サイト（公式 Web サイト・Wikipedia 等）から取得した画像は、各権利者に帰属します。
  3. ユーザー投稿の著作権は投稿者に帰属しますが、第4条のとおり本サービスは利用権を有します。
