# KODOCO

> 今日、子どもとどこいく？

その毎日の問いに答えるために作った、滋賀県の子連れおでかけ Web アプリ。
天気・年齢・外出できる時間から、**今日ぴったりの 1 スポット** が見つかります。

---

## はじめに

| | |
|---|---|
| 公開サイト | <https://kodoco.jp/> |
| 利用料 | **完全無料** |
| 対応エリア | 滋賀県 168 スポット（順次拡充中）|
| 対応端末 | スマートフォン / タブレット / PC（PWA 対応） |
| アカウント | 任意（未登録でも基本機能は使えます） |

iPhone は **Safari →「ホーム画面に追加」** で通常のアプリと同じように使えます。

---

## できること

### 🎯 今日のおすすめ
- 天気 × お子さんの年齢 × 外出できる時間で、**今日ぴったりの 1 スポット** を提案
- 「公園」「室内遊び場」「カフェ」「体験」「犬連れ OK」など 6 カテゴリから絞り込み

### 🗺 168 スポットの詳細情報
- 各スポットの公式サイト・電話番号・地図・営業時間
- 駐車場の有無、所要時間、駅近など細かい情報も
- 写真付きで雰囲気が分かる

### 💬 口コミの投稿・閲覧
- 「実際に行ってみてどうだった？」を、お子さんの年齢付きで投稿
- 同じ年齢の子を連れた他のパパママの声が読める
- 自分の口コミは設定画面から **編集・削除** 可能

### 🎴 10 匹のキャラクター
- スポットを訪れたり口コミを投稿したりすると、キャラクターが解禁される
- ビックリマン風のレアリティ（コモン / レア / ホロ）でコレクション
- 11 種類のあしあとバッジ獲得も

### 📍 スポット投稿
- 「このスポットも追加して！」とユーザーから申請可能（要ログイン）
- 運営の確認後にアプリに反映
- 自分の申請は設定画面から **編集・取り下げ** 可能

### 🔄 端末横断
- アカウント登録すると、お気に入り・口コミ・解禁したキャラがどの端末からでも見られる
- iPhone と PC で同じ状態を共有

---

## 子どもの情報の扱い

- お子さんの年齢・お気に入りなどは、基本的にあなたのブラウザ内（localStorage）にのみ保存されます
- アカウント登録した場合、上記情報はあなただけが見られる形でクラウドにも同期されます
- 投稿された口コミは匿名扱いで、個人を特定できる情報は保存しません

詳しくは [プライバシーポリシー](./privacy.html) を参照してください。
